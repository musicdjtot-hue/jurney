# Сборка Android APK на GitHub («Корускант · Горизонт»)

В проект добавлена полная настройка **Capacitor + GitHub Actions**, которая упаковывает **ту же самую игру**, что вы видите в браузере (с той же 3D-графикой, салоном, спутницей, погодой, квестами, управлением касанием и гироскопом), в полноценный **Android APK**.

## Как собрать APK из архива из вкладки «Versions»

1. Скачайте ZIP-архив проекта из вкладки **Versions** в студии.
2. Создайте новый репозиторий на GitHub и загрузите туда **все файлы из архива** (через `git push` или GitHub Desktop / веб-интерфейс).
   - **Важно при загрузке через браузер**: на Windows/Mac/Android папка `.github` начинается с точки и может быть скрыта в проводнике. Убедитесь, что включён показ скрытых файлов и папка `.github/workflows/build-android-apk.yml` тоже загрузилась в репозиторий.
   - Если `.github` не загрузилась, откройте в репозитории вкладку **Actions → set up a workflow yourself** и вставьте содержимое файла `.github/workflows/build-android-apk.yml`.
3. Откройте вкладку **Actions** в вашем репозитории на GitHub:
   - Сборка **Build Android APK** запустится автоматически при загрузке файлов (или нажмите **Run workflow** вручную).
4. Дождитесь зелёной галочки (~2–3 минуты), откройте завершённый запуск и внизу в разделе **Artifacts** скачайте **`Coruscant-Horizon-APK`** (внутри лежит готовый **`Coruscant-Horizon.apk`**).
5. Установите **`Coruscant-Horizon.apk`** на Android-смартфон.

## Что уже настроено для Android
- Идентичная браузерной сборка (`npm run build` → `dist/`), встроенная локально внутрь APK (работает без интернета).
- Аппаратное ускорение WebGL2 (`hardwareAccelerated="true"`).
- Полноэкранный режим без системных рамок, поддержка выреза камеры (`shortEdges`) и тёмный фон `#06090f`.
- Экран не гаснет во время поездки и полёта (`FLAG_KEEP_SCREEN_ON`).
- Виброотклик кнопок (`VIBRATE`) и поддержка гироскопа в защищённом контексте `https://localhost`.
